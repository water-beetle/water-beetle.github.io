사용자 방향·설계 제안·기록된 구현을 구분합니다. 연구 거래 지원은 장비 실물 기능 완료를 뜻하지 않습니다. 원문을 수정하거나 게임 규칙을 바꾸는 웹이 아닙니다. 정본은 Comet 프로젝트의 `Docs/`이며 이 저장소는 읽기 전용 스냅샷입니다.

검사: `node check.mjs site`

스냅샷 출처와 SHA-256: `source-manifest.json`

이전 게시 내용은 현재 사이트에서 제거했으며 Git 커밋 이력은 보존합니다. 기존 `/devlog/` 및 `/optimization/` 경로에는 새 안내만 표시합니다.
